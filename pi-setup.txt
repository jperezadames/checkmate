CheckMate — Raspberry Pi Setup
Things to install on the Pi before running the system.

Target: Raspberry Pi 5, Raspberry Pi OS (Bookworm or Trixie).


1. SYSTEM PACKAGES (apt)
   Not Python packages — installed with apt, not pip.

     sudo apt update
     sudo apt install stockfish

   - stockfish          Chess engine binary at /usr/games/stockfish
                        (the path config.json expects).
   - Chromium           Ships with Raspberry Pi OS; shows the UI on the screen.
   - python3-picamera2  Only for the Raspberry Pi camera module
                        ("backend": "picamera2" in config.json). The USB webcam
                        ("v4l2", the default) doesn't need it. It must come from
                        apt, which is why the venv below uses --system-site-packages.


2. PYTHON ENVIRONMENT
   Create the venv with --system-site-packages so Picamera2 stays visible
   (harmless when you use the USB webcam).

     python3 -m venv --system-site-packages .venv
     .venv/bin/pip install -r requirements.txt

   requirements.txt (runtime):
     python-chess   engine: board state + Stockfish interface
     numpy (<2)     camera math (pinned for Picamera2 compatibility)
     opencv-python  camera vision / ArUco detection
     pyserial       LED controller: USB serial link to the Pico
     fastapi        backend server
     uvicorn        runs the server

3. ROTARY ENCODER AND SELECT
   Connect a mechanical quadrature encoder and one momentary switch to the
   Pi's GPIO with the Pi powered off. Use the encoder's push switch or a
   separate Select button.

     Encoder A / CLK  -> GPIO17 (physical pin 11)
     Encoder B / DT   -> GPIO27 (physical pin 13)
     Select / SW      -> GPIO22 (physical pin 15)
     Encoder common and switch ground -> GND (physical pin 14)

   Use 3.3 V logic. If the encoder module has a power input and supports
   3.3 V operation, connect it to 3.3 V (physical pin 1). A bare mechanical
   encoder needs only A, B, and ground. Wire a separate Select switch between
   GPIO22 and ground.

   In /boot/firmware/config.txt, remove the previous CheckMate LEFT, RIGHT,
   ENTER, and ESC gpio-key lines if present. Add these in the [all] section:

     dtoverlay=rotary-encoder,pin_a=17,pin_b=27,relative_axis,steps-per-period=1
     dtoverlay=gpio-key,gpio=22,keycode=28,label=CHECKMATE_SELECT

   The rotary overlay reports movement to the bridge, which sends Left/Right.
   The gpio-key overlay sends Enter directly and debounces the switch. Use the
   UI's Back or Close control to return.

   From the repo root on the Pi, install the bridge and enable it at boot:

     sudo apt install python3-evdev evtest
     sudo install -D -m 0644 scripts/pi/rotary_keyboard.py /usr/local/lib/checkmate/rotary_keyboard.py
     sudo install -m 0644 scripts/pi/checkmate-rotary.service /etc/systemd/system/checkmate-rotary.service
     sudo systemctl daemon-reload
     sudo systemctl enable checkmate-rotary.service
     sudo reboot

   After reboot, check `systemctl status checkmate-rotary.service` and run
   `sudo evtest`. Select CheckMate Rotary to check that each detent sends
   one KEY_LEFT or KEY_RIGHT press and release. Select the GPIO keys device
   to check for KEY_ENTER when pressing Select. Then focus Chromium and try
   moving through color, difficulty, and the in-game controls.

   If turning clockwise moves left, swap pin_a and pin_b in the overlay and
   reboot. If the highlight moves every other detent or skips past choices,
   tune steps-per-period (1, 2, or 4) until each detent gives one key tap.
   Check service errors with `journalctl -u checkmate-rotary.service -b`.


4. RUN

     .venv/bin/uvicorn checkmate.server:app --host 127.0.0.1 --port 8000

   Then open http://127.0.0.1:8000 in Chromium (kiosk mode on the screen).
   First run (camera calibration) and troubleshooting: RUNNING.md.


NOTES
   - requirements-dev.txt = requirements.txt + pytest + httpx (tests only).
     Needed only to run the test suite; not required to run the system.
   - The Pico LED firmware is uploaded to the Pico separately with mpremote;
     it is not installed on the Pi.
